화면의 트리와 실제 크기

      

        
4 → 128해시 블록 하나에 담는 해시 수. 화면은 보기 좋게 4개, 실제는 4096 ÷ 32 = 128개

        
1,000 블록 → 94MB 이미지의 해시 블록 수. level 0이 8개, level 1이 1개 (docs/4 실측)

        
1 GiB → 3단블록 하나를 읽을 때 검증하는 해시 블록 수. 트리가 128배씩 줄어서

      

    

  


  
  

    

      
누가 무엇을 실행할 수 있나

      
Bottlerocket 정책의 rules.cil은 host 구성 요소(verified_s)가 dm-verity가 보호하는 immutable 파일만 실행하게 합니다. 파일 위치를 고르면 두 기술 중 어느 쪽이 거부하는지 표시됩니다.
