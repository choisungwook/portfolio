# SSE 응답 타임라인 생성 프롬프트

M3 Pro에서 측정한 두 HTTP 응답을 공통 시간축에 표시하는 한국어 타임라인을 흰 배경 PNG로 만든다. 가로축은 “요청 시작 후 경과 시간 (ms)”로 표시하고 0, 500, 1,000, 1,500, 2,000에 눈금을 둔다.

- 위 행은 “비스트리밍”이다. 0부터 2,053.9 ms까지 회색 점선으로 대기를 표시한다. 끝에 주황색 사각형을 두고 “첫 텍스트 · 응답 완료 2,053.9 ms”라고 표시한다.
- 아래 행은 “SSE”다. 0부터 93.6 ms까지 회색 점선으로 대기를 표시하고, 파란색 원과 “첫 텍스트 93.6 ms” 라벨을 둔다. 이어서 2,049.4 ms까지 실선을 긋고 파란색 사각형과 “응답 완료 2,049.4 ms” 라벨을 둔다.
- 두 행의 마커는 실제 시간에 비례해 배치한다. 실선은 첫 텍스트 수신부터 본문 수신 완료까지의 구간이다.
- 제목은 “비스트리밍과 SSE의 응답 타임라인”이다. 부제에는 M3 Pro, LiteLLM + Ollama, 워밍업 후 각 모드 1회 실측을 적는다.

실측값의 눈금과 한글을 정확히 배치할 수 있도록 Matplotlib과 Apple SD Gothic Neo를 사용했다. [타임라인 PNG](http-vs-sse-timeline.png)
