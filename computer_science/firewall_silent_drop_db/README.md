# (아이디어) 보안장비 silent drop으로 인한 DB 커넥션 장애 재현

이 핸즈온은 아직 구현하지 않은 아이디어 단계다. 실습 코드와 실측 결과는 없고, 의도와 설계만 정리했다.

`애플리케이션 -> 보안장비 -> PostgreSQL primary/replica` 경로에서 보안장비가 RST를 보내지 않고 세션을 끊거나 정상 쿼리를 오탐으로 drop하면, 애플리케이션은 끊긴 사실을 모른 채 응답을 기다리고 DB는 주인 없는 세션을 계속 붙잡는다. 이 현상을 전부 오픈소스로 로컬에서 재현하고 Grafana로 관측하는 것이 목표다.
