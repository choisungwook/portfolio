READ THE MODEL

A capacity estimate, not a benchmark.

01

Measure the same workload

Benchmark the same model, GPU shape, quantization, prompt/output distribution, and concurrency that production will use.

02

Separate the two budgets

Each request consumes prompt tokens from prefill capacity and generated tokens from decode capacity. The smaller RPS limit wins.

03

Keep operational reserve

The reserve absorbs traffic variance, long prompts, scheduler effects, and tail latency. It is not a guarantee against overload.
