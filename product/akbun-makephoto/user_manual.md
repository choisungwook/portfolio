# akbun-makephoto 사용자 매뉴얼

akbun-makephoto는 macOS용 사진 카탈로그 겸 편집기입니다. 사진 편집을 해 본 적 없는 사람이 폴더를 가져오고, 태그와 별점으로 정리하고, 버튼 하나로 밝기와 색을 고친 뒤 JPEG로 내보내는 데까지를 목표로 만들었습니다. 이 문서는 그 순서대로 앱을 설명합니다. 같은 기능을 터미널에서 쓰는 `makephoto` CLI는 마지막 절에 있습니다.

## 원본 사진은 바뀌지 않고 복사되지도 않습니다

사진을 가져오면 앱은 사진 파일의 경로만 기록합니다. 파일을 앱 폴더로 복사하지 않고, 편집해도 원본 파일에 쓰지 않습니다. 편집은 "밝기 +0.5, 대비 +15" 같은 숫자로 카탈로그 파일에 저장되고, 화면에 보이는 결과는 그 숫자를 원본에 그때그때 적용해 그린 미리보기입니다. 편집이 새 픽셀이 되는 시점은 **Export** 하나뿐이고, 그때도 원본 옆이 아니라 고른 폴더에 새 JPEG를 만듭니다.

그래서 사진이 외장 드라이브에 있어도 내장 디스크는 거의 쓰지 않습니다. 내장 디스크에 생기는 파일은 아래 3개뿐입니다.

| 파일 | 내용 |
|---|---|
| `~/Library/Application Support/io.akbun.makephoto/catalog.json` | 가져온 사진의 경로, 태그, 별점, 편집 숫자 |
| `~/Library/Application Support/io.akbun.makephoto/settings.json` | 화면 모드와 내보내기 품질 |
| `~/Library/Caches/io.akbun.makephoto/thumbs/` | 목록에 쓰는 작은 썸네일. 지워도 다시 만듭니다 |

## 설치한 뒤 터미널 명령을 1번 실행합니다

앱은 서명하지 않은 빌드라서 처음 실행할 때 macOS가 막습니다. 설치 순서는 다음과 같습니다.

1. GitHub Releases에서 `akbun-makephoto-v<버전>` 릴리스의 dmg를 받습니다. Apple Silicon Mac용입니다.
2. dmg를 열고 **akbun-makephoto**를 **Applications**로 끌어다 놓습니다.
3. 터미널에서 아래 명령을 1번 실행합니다.

macOS가 붙인 격리 표시를 지우는 명령입니다.

```bash
xattr -cr /Applications/akbun-makephoto.app
```

새 버전은 **Settings** 메뉴의 **Check for Updates…**로 받습니다. 앱이 스스로 내려받아 설치하고 다시 시작하므로 이 명령을 다시 실행할 필요는 없습니다.

## 화면은 Library와 Edit 두 모드로 나뉩니다

위쪽 막대 왼쪽에는 **File**, **Edit**, **Photo**, **View**, **Settings** 메뉴가 있고, 오른쪽에는 **Library**와 **Edit** 탭이 있습니다. 키보드로는 `G`가 Library, `E`가 Edit입니다.

- **Library**는 정리하는 화면입니다. 왼쪽에 **Catalog**, **Folders**, **Tags** 목록, 가운데에 사진 격자, 오른쪽에 고른 사진의 이름, 경로, 별점, 태그가 있습니다.
- **Edit**는 사진 1장을 고치는 화면입니다. 가운데에 사진, 그 아래에 도구 막대와 필름 스트립, 오른쪽에 조정 패널이 있습니다.

조정 패널은 **Histogram**, **Auto**, **Light**, **Color**, **Film Looks** 순서로 쌓여 있고, 제목을 누르면 접고 펼 수 있습니다. **Histogram**은 사진에서 어두운 쪽(왼쪽)부터 밝은 쪽(오른쪽)까지 픽셀이 얼마나 있는지를 빨강, 초록, 파랑으로 겹쳐 그립니다. 그래프가 오른쪽 끝에 붙어 있으면 하늘처럼 밝은 부분이 하얗게 날아갔다는 뜻입니다.

화면 색은 Dark가 기본입니다. 창 오른쪽 아래의 둥근 버튼을 누르면 Light와 Dark가 바로 바뀌고, 다음에 앱을 열 때도 그 색으로 시작합니다. 버튼의 해 아이콘은 Light로, 달 아이콘은 Dark로 바꾼다는 뜻입니다. macOS 설정을 따르게 하려면 **Settings → Preferences…**(`⌘,`)의 **Appearance**에서 **Follow the system**을 고릅니다.

## 사진 가져오기

폴더째 가져오는 방법이 가장 빠릅니다.

1. **File → Import Folder…**(`⇧⌘I`)를 고릅니다.
2. 사진이 든 폴더를 고릅니다. 하위 폴더까지 모두 찾습니다.

사진 몇 장만 넣으려면 **File → Import Photos…**(`⌘I`)를 씁니다. Finder에서 사진이나 폴더를 앱 창에 끌어다 놓아도 됩니다.

가져오기가 끝나면 아래쪽에 결과가 잠깐 표시됩니다. 이미 카탈로그에 있는 사진은 다시 넣지 않고 "already in the catalog"로 세며, 사진이 아닌 파일은 "skipped"로 셉니다.

읽을 수 있는 형식은 JPEG, PNG, TIFF, WebP, HEIC와 카메라 RAW(RAF, ARW, CR2, CR3, NEF, DNG 등)입니다. HEIC와 RAW는 macOS에 들어 있는 이미지 엔진으로 엽니다.

## 태그와 별점으로 사진을 찾습니다

먼저 사진을 고릅니다. 클릭하면 1장, `⌘`를 누른 채 클릭하면 1장씩 더하거나 빼고, `Shift`를 누른 채 클릭하면 사이의 사진을 모두 고릅니다. `⌘A`는 지금 보이는 사진을 모두 고릅니다.

- **태그 붙이기**: 오른쪽 **Tags** 칸에 이름을 쓰고 Enter를 누릅니다. 쉼표로 나누면 여러 개를 한 번에 붙입니다. 고른 사진 전부에 붙습니다.
- **태그 떼기**: 태그 옆의 **×**를 누릅니다. 고른 사진 일부에만 있는 태그는 기울어진 글씨로 표시됩니다.
- **태그 이름 바꾸기**: 왼쪽 **Tags** 목록에서 태그를 더블클릭하고 새 이름을 씁니다. 그 태그가 붙은 모든 사진에서 바뀝니다.
- **별점**: 오른쪽 별을 누르거나 숫자 키 `1`부터 `5`를 누릅니다. 같은 별을 다시 누르거나 `0`을 누르면 별점이 지워집니다.

찾을 때는 왼쪽 목록과 위쪽 막대를 씁니다. 왼쪽에서 폴더나 태그를 누르면 그것만 보이고, **Edited**는 편집한 사진만 보여 줍니다. 위쪽 검색 칸은 파일 이름과 태그를 함께 찾고, 옆의 별점 목록은 그 별점 이상인 사진만 남깁니다.

## 편집은 자동 보정 버튼으로 시작합니다

사진을 더블클릭하거나 **Edit Photo**를 누르면 Edit 모드로 들어갑니다. 무엇을 고쳐야 할지 모르겠다면 **✨ Auto Fix**(`⇧A`)를 먼저 누르고, 결과를 보며 슬라이더로 다듬는 순서를 권합니다.

### 자동 보정 버튼은 맡은 슬라이더만 바꿉니다

**Auto Fix**는 사진을 분석해 아래 5가지를 차례로 실행합니다. 하나만 필요하면 그 버튼만 누릅니다. 기울기는 사진 틀을 바꾸는 작업이라 여기서 하지 않고, 아래 "수평을 맞춥니다"의 Level 모드에서 확인하고 저장합니다.

| 버튼 | 바꾸는 슬라이더 | 하는 일 |
|---|---|---|
| **Color** | Warmth, Tint | 사진 전체가 노랗거나 파랗게 뜬 기운을 줄입니다 |
| **Brightness** | Brightness | 너무 어둡거나 밝은 사진을 보기 편한 밝기로 옮깁니다 |
| **Light & Shadow** | Bright areas, Dark areas | 하얗게 날아간 하늘을 되살리고 어두운 곳을 엽니다 |
| **Contrast** | Contrast | 뿌옇고 밋밋한 사진에 깊이를 줍니다 |
| **Vivid** | Vibrance | 칙칙한 색을 살립니다 |

버튼은 다른 버튼이 맡은 슬라이더를 건드리지 않습니다. 그래서 **Contrast**만 다시 눌러도 직접 맞춘 밝기는 그대로 남습니다.

자동 보정은 목표값까지 끝까지 가지 않고 일부만 움직입니다. 예를 들어 **Brightness**는 계산한 보정량의 75%만 적용하고 ±2 stop을 넘기지 않습니다. 노을 사진이 회색으로 바뀌거나 어두운 실내가 대낮처럼 바뀌지 않게 하려는 선택입니다.

버튼을 누르면 값이 바뀐 슬라이더 줄이 잠깐 민트색으로 빛나고, 버튼 아래에 버튼마다 1줄씩 결과가 표시됩니다.

- **Contrast: Contrast +24**처럼 슬라이더 이름과 새 값이 나오면 그 값으로 바뀐 것입니다.
- **already fine, nothing changed**는 사진에 그 보정이 필요 없어 0으로 둔 것입니다.
- **unchanged**는 다시 재 보니 이미 맞춰 둔 값과 같아서 그대로 둔 것입니다.

### 슬라이더는 놓을 때 저장됩니다

슬라이더를 끄는 동안에는 미리보기만 바뀌고, 손을 떼는 순간 저장되면서 되돌리기 1단계가 생깁니다. 슬라이더 이름을 더블클릭하면 그 값만 0으로 돌아갑니다.

| 슬라이더 | 범위 | 하는 일 |
|---|---|---|
| Brightness | −3 ~ +3 | 사진 전체를 밝게 또는 어둡게 합니다. 단위는 stop입니다 |
| Contrast | −100 ~ +100 | 올리면 선명하고 내리면 부드러워집니다 |
| Bright areas | −100 ~ +100 | 내리면 밝은 하늘이 돌아옵니다 |
| Dark areas | −100 ~ +100 | 올리면 그림자 속이 보입니다 |
| Warmth | −100 ~ +100 | 왼쪽은 푸르게, 오른쪽은 노랗게 합니다 |
| Tint | −100 ~ +100 | 왼쪽은 초록, 오른쪽은 자홍 쪽입니다 |
| Vibrance | −100 ~ +100 | 피부색은 덜 건드리고 칙칙한 색만 살립니다 |
| Saturation | −100 ~ +100 | 모든 색을 강하게 또는 약하게 합니다. 맨 왼쪽은 흑백입니다 |

### 원본과 비교하고 되돌립니다

사진 아래 도구 막대의 눈 아이콘을 누르고 있거나 `\` 키를 누르고 있으면 편집 전 사진이 보입니다. 도구 막대의 아이콘은 글씨 없이 그림만 있고, 마우스를 올리면 이름과 단축키가 나타납니다. 손을 떼면 편집한 사진으로 돌아옵니다.

되돌리기는 `⌘Z`, 다시 하기는 `⇧⌘Z`이고 도구 막대 왼쪽의 굽은 화살표 2개도 같습니다. 되돌리기 기록은 사진마다 따로 있어서 다른 사진으로 옮겨 갔다 와도 남아 있습니다. **Reset All**은 그 사진의 편집을 모두 지웁니다.

### 필름 룩은 색 레시피 10가지입니다

오른쪽 패널 맨 아래의 **Film Looks** 목록에서 이름을 누르면 바로 적용됩니다. 각 이름 옆의 작은 그림은 지금 사진에 그 룩을 입힌 미리보기입니다. 룩을 고르면 목록 아래에 **Strength** 슬라이더가 생기고, 0에서 100까지 강도를 정합니다. 룩은 슬라이더 조정 위에 얹히므로 Brightness나 Warmth를 함께 써도 됩니다.

| 이름 | 느낌 |
|---|---|
| Vivid Slide | 진한 색과 깊은 대비. 풍경에 어울립니다 |
| Soft Portrait | 부드러운 대비와 따뜻한 피부색 |
| Muted Street | 차분한 색과 단단한 그림자. 거리 사진에 어울립니다 |
| Warm Negative | 들뜬 검정, 차가운 그림자, 따뜻한 밝은 부분 |
| Cool Negative | 들뜬 검정과 초록빛이 도는 푸른 기운 |
| Faded Matte | 낮은 대비, 부드러운 검정, 옅은 색 |
| Teal & Orange | 차가운 그림자와 따뜻한 피부. 영화 같은 느낌입니다 |
| Golden Hour | 늦은 오후의 따뜻한 빛 |
| Classic Mono | 균형 잡힌 흑백 |
| Gritty Mono | 거친 입자가 있는 강한 흑백 |

모든 룩은 이 앱이 직접 정한 숫자로 만든 레시피입니다. 특정 필름이나 카메라 제조사의 색을 재현하지 않습니다.

### 수평은 Level 모드에서 맞추고 OK로 저장합니다

기울기는 Level 모드에서 맞춥니다. 모드 안에서 바꾼 각도는 미리보기에만 보이고, **OK**를 누를 때 저장됩니다. 저장하기 전까지는 Auto Level과 슬라이더를 몇 번이든 다시 써 볼 수 있습니다.

1. 도구 막대의 수평 아이콘(바닥선 위에 기울어진 선)을 누르거나 `L`을 누릅니다. 사진 위에 격자가 나타나고, 도구 막대 자리에 Level 막대가 나옵니다.
2. **Auto Level**을 누르면 앱이 수평선이나 수직선을 찾아 ±10도 안에서 각도를 맞춥니다. 믿을 만한 직선이 없으면 "Level: no clear horizon or vertical line, left as is"를 표시하고 각도를 바꾸지 않습니다. 언덕이나 나무처럼 곧은 선이 없는 사진을 엉뚱하게 기울이지 않기 위해서입니다.
3. **Angle** 슬라이더로 −45도에서 +45도까지 직접 돌립니다. 격자의 가로선과 수평선이 나란해지면 됩니다. **Angle** 글자를 더블클릭하면 0도로 돌아갑니다.
4. **OK**나 Enter로 저장합니다. **Cancel**이나 Escape는 모드를 열기 전 각도로 되돌립니다.

Level 모드가 열려 있는 동안 오른쪽 패널과 필름 스트립은 흐리게 잠깁니다. 다른 메뉴나 단축키를 쓰면 저장하지 않고 모드를 닫습니다. 사진을 돌리면 앱이 사진을 조금 확대해 빈 모서리가 생기지 않게 합니다. 90도 회전은 도구 막대의 둥근 화살표 아이콘 2개나 `[`, `]` 키로 합니다.

### 자르기는 비율 버튼으로 바로 시작합니다

자르는 순서는 다음과 같습니다.

1. 도구 막대의 자르기 아이콘(직각 2개가 겹친 모양)을 누르거나 `C`를 누릅니다. 사진 위에 3등분 격자가 있는 틀이 나타납니다.
2. 아래 막대의 비율 버튼을 누릅니다. **Free**, **Original**, **1:1**, **4:3**, **3:2**, **16:9**, **4:5**가 있고, 누르는 즉시 그 비율로 가장 크게 잡은 틀이 사진 가운데에 나타납니다. 고른 비율은 민트색으로 표시됩니다.
3. 틀 안을 끌어 위치를 옮기고, 네 모서리를 끌어 크기를 바꿉니다. 비율 버튼으로 고른 비율은 크기를 바꿔도 유지됩니다. **Free**에서 Shift를 누른 채 모서리를 끌면 끌기 시작할 때의 모양을 유지합니다.
4. **Done**이나 Enter로 끝냅니다. **Cancel**이나 Escape는 바꾼 내용을 버리고, **Whole Photo**는 자르기를 없앱니다.

90도 회전을 하면 자르기가 지워집니다. 자른 범위는 회전 전 방향을 기준으로 저장되기 때문입니다.

### 편집을 다른 사진에 붙여 넣습니다

같은 장소에서 찍은 사진은 편집 하나를 여러 장에 나눠 쓰면 빠릅니다.

1. 잘 고친 사진에서 **Edit → Copy Edit**(`⇧⌘C`)을 고릅니다.
2. Library에서 붙일 사진들을 고릅니다.
3. **Edit → Paste Edit to Selected**(`⇧⌘V`)를 고릅니다.

붙여 넣을 때 밝기, 색, 룩은 옮겨지지만 자르기, 90도 회전, 기울기는 각 사진의 값이 그대로 남습니다. 구도는 사진마다 다르기 때문입니다.

## 내보내기는 새 JPEG를 만듭니다

1. 내보낼 사진을 고릅니다. Edit 모드에서는 지금 보고 있는 사진입니다.
2. **File → Export Selected…**(`⌘E`)를 고릅니다.
3. 저장할 폴더를 고릅니다.

원본 크기 그대로 편집을 적용한 JPEG가 만들어집니다. 같은 이름의 파일이 이미 있으면 덮어쓰지 않고 `IMG_1234-2.jpg`처럼 번호를 붙입니다. JPEG 품질은 **Preferences**의 **Export JPEG quality**에서 50부터 100까지 정하며 기본값은 92입니다.

## 외장 드라이브를 빼도 편집은 남습니다

드라이브를 빼면 그 드라이브의 사진은 흐리게 표시되고, 왼쪽 **Folders** 목록의 폴더 옆에 "offline"이 붙습니다. 태그, 별점, 편집은 카탈로그에 그대로 있으므로 정리는 계속할 수 있습니다. 미리보기와 내보내기만 원본이 필요합니다. 드라이브를 다시 꽂으면 앱이 10초쯤 안에 사진을 다시 찾고, 앱 창을 누르면 바로 찾습니다.

드라이브 이름을 바꿨거나 폴더를 옮겼다면 앱이 예전 경로로는 사진을 찾지 못합니다. 이때는 offline 폴더 옆의 **Locate…**를 누르고 지금 위치의 폴더를 고릅니다. 그 폴더 아래 사진의 경로가 한 번에 바뀌고 편집은 그대로 이어집니다.

## 카탈로그에서 빼도 파일은 지워지지 않습니다

사진을 고르고 Delete 키를 누르거나 **File → Remove from Catalog…**를 고르면 카탈로그에서 빠집니다. 그 사진의 태그와 편집은 잊히지만 디스크의 사진 파일은 그대로 있습니다.

## CLI로 같은 카탈로그를 다룹니다

앱의 실행 파일은 `makephoto` CLI이기도 합니다. 앱을 열지 않아도 같은 카탈로그를 읽고 쓰므로, 스크립트나 AI agent에게 정리와 보정을 맡길 때 씁니다. 모든 명령은 결과를 JSON으로 출력하고, 앱이 열려 있으면 2초 안에 화면에 반영됩니다.

처음 1번은 `makephoto`라는 이름으로 쓸 수 있게 연결합니다. 앱의 **Settings → Command Line Tool…**에서도 같은 명령을 복사할 수 있습니다.

```bash
mkdir -p ~/.local/bin && ln -sf /Applications/akbun-makephoto.app/Contents/MacOS/akbun-makephoto ~/.local/bin/makephoto
```

자주 쓰는 명령은 다음과 같습니다. 폴더를 가져오고, beach 태그가 붙은 사진을 찾고, 12번 사진의 밝기와 수평만 자동 보정한 뒤, 대비를 올리고 Golden Hour 룩을 입혀 바탕화면으로 내보냅니다.

```bash
makephoto import ~/Pictures/trip
makephoto list --tag beach
makephoto auto 12 --kind brightness --kind straighten
makephoto edit 12 --set contrast=15 --look golden-hour
makephoto export 12 --dir ~/Desktop/out
```

`auto`에 `--dry-run`을 붙이면 저장하지 않고 결과만 출력합니다. 슬라이더 이름과 범위는 `makephoto fields`, 룩 이름은 `makephoto looks`로 확인합니다. 모든 명령은 [CLI reference](./wiki/cli.md)에 있습니다.
