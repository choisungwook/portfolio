      Command Line Tool

      The app's own binary is also a command line tool. It works on the same catalog, with or without the app open, and prints JSON. Changes appear in the open app within two seconds.

      Make it available as makephoto:

      
      
      Then, for example:
      
      
      makephoto list --tag trip
makephoto auto 12 --kind brightness --kind contrast
makephoto edit 12 --set exposure=0.4 --look golden-hour
makephoto export 12 13 --dir ~/Desktop/out
makephoto --help
