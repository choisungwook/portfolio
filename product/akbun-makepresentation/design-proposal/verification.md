# UI 시안 검증

- 확인일: 2026-09-06.
- 환경: Codex 내장 브라우저.
- 검사 대상: 제안용 HTML과 기존 브라우저 편집 로직.
- 설치 패키지·배포·서명·네이티브 앱 실행 없음.

## 제안 화면 검증

- 현재 화면 ↔ 개선안: 슬라이드와 선택 내용 유지.
- 빈 영역 클릭: 비활성 속성 대신 선택 안내 표시.
- 도형 더블클릭: 텍스트 편집 진입.
- 텍스트 수정: 캔버스 반영 및 미저장 상태 표시.
- 실행 취소: 텍스트와 도형 이동 복원.
- 드래그: 도형이 입력한 이동 거리만큼 이동.
- 슬라이드 추가: 4장에서 5장으로 변경, 실행 취소 시 복원.
- 패널 접기·펼치기 정상.
- 저장: 데스크톱 앱 필요 안내 표시.
- AI: 데스크톱 앱 필요 상태 표시.
- 개선 이유: 설명 창 열기·닫기 정상.
- 1280×720, 1000×640: 가로 문서 넘침 없음.
- 390×844: 가로 문서 넘침 없음, 패널 열기 제공.
- 슬라이드: 16:9 비율 유지.
- 브라우저 console 오류·경고 없음.
- JavaScript 구문 검사 통과.

## 언어 검증

- 저장한 선택이 없는 첫 실행: 영어 표시, 문서 lang=en.
- 한국어 선택: 메뉴·도구 이름·속성·단축키 안내·설정 일반 탭·개선 이유 전환.
- 한국어 상태에서 새로고침: 한국어 유지.
- 영어 재선택 후 새로고침: 영어 유지.
- AI 새 대화: 모드 이름·입력창 안내·퀵 버튼·기준 슬라이드 전환.
- 현재 화면 ↔ 개선안: 선택한 언어 유지.
- 슬라이드의 Save 문구와 AI 입력값: 언어 전환 후 원문 유지.
- 영어 1000×640, 영어·한국어 390×844: 가로 문서 넘침 없음.
- 최종 1280×720 영어·한국어 PNG 저장, console 오류·경고 없음.

## 범위

- 실제 파일 입출력·AI 생성은 검증 대상에서 제외.
- 스크린리더 사용성·네이티브 대화상자 번역·창 동작은 후속 구현 범위.
- 접근성 전체 준수나 모든 기존 기능의 회귀 검증을 의미하지 않음.
