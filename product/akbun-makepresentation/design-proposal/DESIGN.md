# 발표 편집기 UI 제안

## 방향

- macOS 기본 앱처럼 익숙하고 절제된 도구 중심.
- 핵심 작업: 슬라이드 선택 → 도형·텍스트 편집 → 결과 확인.
- 표현의 중심: 사용자가 만드는 슬라이드.
- 기존 도형·코드·AI 편집 모델 유지.
- 짧은 도구 이름, 선택 문맥, 작업면 확보를 우선.
- 기본 화면 언어는 영어, 지원 언어는 영어·한국어.
- 상단 언어 선택은 현재 화면·개선안에서 공통으로 적용.
- 언어 선택은 로컬에 저장하며 슬라이드 내용과 입력값은 번역하지 않음.

## 화면 기준

| 역할 | 값 |
|---|---|
| 도구 배경 | #f6f6f6 |
| 패널 | #fafafa |
| 작업면 주변 | #e6e6e6 |
| 본문 | #252525 |
| 보조 글자 | #686868 |
| 선택 강조 | #0a64c4 |

- UI 글꼴: macOS 시스템 글꼴과 Apple SD Gothic Neo.
- 슬라이드 글꼴: 기존 Noto Sans KR.
- 도구 이름 11~12px, 속성 12~13px, 문서 제목 14px.
- 문서 정보와 속성명은 왼쪽 정렬.
- 도구 버튼 안의 아이콘과 이름은 가운데 정렬.
- 166px 슬라이드 목록, 가변 작업면, 248px 속성 패널.
- 이미지 생성 시안의 큰 리본·균일한 파란 카드·반짝이 장식 제외.
- 그림자와 둥근 모서리는 창·버튼처럼 역할이 있는 곳에만 사용.
- 실행 취소, 다중 선택, 드래그, 잠금 등 원래 편집 동작 유지.

## 적용 범위

- 실제 앱 소스를 읽는 독립 제안 화면.
- 저장·내보내기·AI 실행은 데스크톱 경계 안내.
- 핵심 편집과 전후 비교를 위한 제안이며 실제 앱 반영 전 단계.
- 메뉴·도구·속성·설정·AI 입력 안내·개선 이유의 언어 전환 제공.
- 전체 접근성 검증과 네이티브 대화상자 번역은 실제 앱 반영 단계에서 수행.
