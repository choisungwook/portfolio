## 결정

- design-proposal의 기본 언어는 영어, 지원 언어는 영어·한국어.
- 언어 선택은 현재 화면·개선안 비교와 독립적으로 유지.
- 슬라이드 본문, 문서 이름, 사용자 입력은 원문 유지.
- 실제 앱 반영 전 검토하는 독립 HTML 시안에 적용.

## 이유

- 화면 조작 언어와 발표 자료의 언어는 서로 다를 수 있음.
- 메뉴를 번역할 때 편집 내용이 바뀌면 문서의 의미가 달라짐.
- 선택 언어를 유지하면 다시 열 때 언어를 고르는 반복을 줄일 수 있음.
