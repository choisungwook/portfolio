## 결정

- stage 또는 속성 패널 포커스에서 현재 슬라이드의 모든 도형 선택.
- 슬라이드 패널 포커스에서 모든 슬라이드 선택.
- 입력 필드와 텍스트 편집기는 운영체제의 텍스트 전체 선택 유지.

## 이유

- 같은 단축키의 대상을 포커스 영역으로 한정하면 도형과 슬라이드의 동시 선택 방지.
- 입력 필드의 기본 동작을 보존해야 텍스트 편집 단축키와 충돌하지 않음.
