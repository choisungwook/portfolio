## 결정

- 기본 폰트와 테두리를 앱 데이터 디렉터리의 settings.json에 저장.
- 도형과 이미지의 테두리 색상·굵기·스타일을 별도로 저장.
- 도형 테두리 설정은 사각형·원·선·화살표·펜에 공통 적용.
- Noto Sans KR 가변 폰트와 OFL 라이선스를 앱에 포함.
- 저장된 기본값은 이후 생성하는 객체에만 적용.
- 채우기·글자 색상과 화살표 시작·끝 모양도 같은 설정에 저장.
- 테두리 없음은 채우기와 같은 `none` 값으로 저장하고 굵기는 유지.
- Inspector는 선택 객체만 변경하고 새 객체는 매번 저장된 기본값에서 생성.
- 화살표 기본 끝 모양은 화살표 도구에만 적용하고 선·펜은 끝 모양 없이 생성.

## 이유

- 문서 내용과 사용자 편집 환경을 분리해야 함.
- 이미지와 도형은 서로 다른 기본 테두리가 필요함.
- 운영체제에 폰트가 없어도 동일한 편집 결과를 표시해야 함.
- 마지막 편집 색상이 다음 객체로 전파되면 저장한 기본값과 실제 생성 결과가 어긋남.
