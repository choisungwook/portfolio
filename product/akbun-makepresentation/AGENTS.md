# Agent Guide

Root `AGENTS.md`의 공통 규칙을 먼저 따른다.

## Human wiki

- 기능 구현과 검증이 모두 끝난 뒤, 사용자가 직접 이해해야 하는 내용을 `human-wiki/`에 기록한다.
- 구현 절차보다 아키텍처 경계, 핵심 불변식, 의사결정, 선택 이유, 트레이드오프, 실패 방식을 우선한다.
- 코드에서 다시 쉽게 찾을 수 있는 함수 목록이나 작업 일지는 기록하지 않는다.
- 근거가 되는 코드와 ADR을 상대 경로와 `file:line`으로 연결한다.
- 같은 주제는 새 문서를 늘리기보다 기존 문서를 갱신한다.
- 새 문서를 만들면 `human-wiki/index.md`에 링크를 추가한다.
- 다른 product의 구현에서 얻은 학습 내용도 대상 product와 소스 경계를 명시하면 기록할 수 있다.
- 비밀값, 로컬 사용자 경로, 세션 자격증명은 기록하지 않는다.

문서 끝에는 내용을 스스로 설명할 수 있는지 확인하는 질문을 3~5개 둔다.
