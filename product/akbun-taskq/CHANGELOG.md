## 0.9.0

### Added

- 역할별 상주 bot을 추가했다. bot마다 역할과 세션을 갖고, 메시지를 받을 때마다 같은 세션을 이어서 일한다. `bots.enabled`로 켜며 기본은 꺼져 있다.
- bot끼리 비동기 메시지로 일을 넘긴다. 시작 버튼으로 돌린 태스크의 결과는 그 태스크를 맡은 bot에게 메시지로 돌아온다.
- bot이 함께 쓰는 wiki를 SQLite에 두었다. 쓸 때마다 이전 revision이 남고, 두 bot이 같은 페이지를 동시에 고치면 뒤의 쓰기가 거절된다.
- 화면 왼쪽 메뉴에 Bots 목록이 생겼다. bot마다 최근 메시지와 시각이 보이고, 누르면 그 bot과의 대화를 메신저처럼 보고 메시지를 보낸다. `taskq bots` 명령으로도 같은 일을 한다.
- 일일 예산, agent별 시간당 턴 수, 열린 작업 수, 메시지 재시도 횟수에 상한을 두었다. 상한에 걸리면 bot 전체가 멈추고 경고 하나가 뜬다.
- `bots.personaSkill`에 사용자 대리 판단용 skill 폴더를 지정하면 taskq와 리뷰 bot이 그 기준으로 판단하고 리뷰한다.
- 작업마다 owner bot이 하나다. Board 카드의 배지와 bot 대화 위의 작업 칩에서 누가 무엇을 맡았는지 보고, 작업 상세에서 owner를 바꾼다. bot이 열린 작업과 비슷한 작업을 만들면 거절된다.
- bot끼리 순서와 라운드가 정해진 토론을 열고, 연 bot이 결론을 wiki에 남긴다.
- wiki 검색이 단어 일부(한국어 조사 포함)로 찾고 `[[slug]]` 링크로 이어진 페이지까지 보여준다. 페이지를 `wiki/` 폴더에 markdown으로 내보내 graphify 같은 도구로 색인할 수 있다.
- bot이 시각을 정해 메시지를 예약할 수 있다.

- bot을 직접 만들고 지운다. 처음에는 삭제할 수 없는 오케스트레이터 bot `taskq`만 있고 목록 맨 위에 고정된다. planner, coder, reviewer, doc-reviewer 프리셋에서 시작할 수 있다.
- bot이 자기가 맡은 태스크를 가져가 실행 중으로 바꾸고 직접 처리한 뒤 결과를 남긴다. 그 실행은 Calendar에 bot 이름으로 남는다.
- bot마다 권한 모드(기본 auto), 샌드박스(기본 끔), 차단 명령(기본 없음), 작업 디렉터리, 모델을 설정한다. 모든 bot은 taskq의 데이터와 설정에 접근할 수 없다.
- 글로벌 설정에서 bot용 skill과 plugin을 등록하고, bot마다 고른다. bot에서 오른쪽 버튼을 누르면 Reload skills, Reload plugins, 새 세션, 끄기, 지우기 메뉴가 나온다.
- 글로벌 설정에서 글꼴과 글자 크기를 바꾼다.
- 맡은 bot이 없는 태스크를 큐가 자동으로 실행할지 글로벌 설정에서 정한다.

### Changed

- 태스크의 시작 버튼은 어느 bot에도 속하지 않는 일회성 실행이다. 큐는 bot이 맡은 태스크를 자동으로 실행하지 않는다.
- bot 아바타를 이름 첫 글자를 넣은 단순한 원으로 바꿨다.
- 화면 위의 탭 줄을 왼쪽 메뉴로 옮겼다.
- 기본 디자인을 다크 우선의 둥근 테마로 바꿨다. bot마다 색과 모양이 다른 아바타가 붙는다. 이전 Carbon 테마는 파일로 남아 있다.

## 0.8.0

### Added

- Windows 데스크톱에서 인계와 중요 경고 알림을 표시한다. WSL2에서 실행 중인 taskq도 Windows에 알림을 보낼 수 있다.
- Settings의 Desktop notifications에서 운영체제 알림을 켜고 끌 수 있다. 설정과 앱 내 알림 기록은 재시작 후에도 유지된다.

## 0.7.0

### Added

- 후속 태스크가 완료된 선행 태스크의 실행 ID, 요약과 지정된 산출물 경로를 전달받는다. `Depends on`으로 조사, 설계, 구현을 연결할 수 있다.
- 인계가 도착하면 SQLite에 이력과 알림을 남기고 macOS 알림을 요청한다. 자동 수락을 끈 태스크는 수동 수락을 기다린다.
- 화면과 CLI에서 인계 내역을 보고 수락 모드를 바꿀 수 있다. AI 에이전트는 `taskq mcp`의 읽기 도구로 같은 이력과 수락 설정을 조회할 수 있다.
- Codex의 push 및 PR 생성 전 검사와 GitHub Actions에서 현재 버전의 CHANGELOG 항목을 확인한다.

### Changed

- 태스크를 가져오는 DB 갱신에서도 선행 태스크 상태를 확인해, 선택 직후 선행 작업이 재실행되면 후속 작업을 대기시킨다.
- GitHub 릴리즈 노트의 변경 사항을 해당 버전의 CHANGELOG에서 가져온다.

### Removed

- taskq 릴리즈 노트에서 PR 제목을 모아 변경 사항을 생성하던 방식을 제거했다.

## 0.6.0

### Added

- 보드의 상태별 카드에서 즉시 실행할 수 있다. 검토 완료 또는 종료된 태스크도 다시 실행할 수 있다.

### Changed

- 기본 폴링 간격을 2초에서 60초로 늘렸다. 같은 프로세스의 API 작업과 실행 종료는 큐를 즉시 깨운다.

## 0.5.0
