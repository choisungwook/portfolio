# akbun-taskq 0.30.2

## Changed

- 작업 상세 창을 설정 창처럼 창 가장자리만 남기고 화면을 채우도록 키웠다. 제목은 H1, 의도·파일·Runs·알림은 위 여백과 아래 구분선이 있는 H2 절이고, 블록 사이 간격을 넓혀 촘촘하지 않게 읽힌다.
- 작업 상세에 생성 시각(Created)을 수정 시각 위에 보인다.
- task 상태보드의 열을 모두 같은 너비로 놓는다. 한 줄에 몇 개 들어갈지는 창 너비로만 정해지고, 줄마다 열 개수가 달라 너비가 들쭉날쭉하던 모습이 사라졌다. 카드가 많은 열은 그 열 안에서 스크롤된다.
