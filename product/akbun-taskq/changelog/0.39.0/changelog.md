# akbun-taskq 0.39.0

## Changed

- 데스크톱 앱의 시작 화면 글씨를 키우고, 진행 막대와 함께 "60% starting the server"처럼 지금 단계와 퍼센트를 보인다.
- 시작에 실패하면 taskq가 마지막으로 출력한 200줄을 코드 블록으로 보이고, "로그 복사" 버튼으로 복사한다.
- `taskq run`이 시작하는 동안 `taskq starting <퍼센트> <단계>` 줄을 출력한다(설정 읽기, 데이터베이스 열기, skill 쓰기, runner 준비, 서버, 큐, bot, 준비 완료).

시작 화면은 데스크톱 앱 껍데기에 있어 새 dmg를 설치해야 바뀐다. 설정 > 업데이트는 taskq 실행 파일만 바꾼다.

## SDK

변화 없음.
