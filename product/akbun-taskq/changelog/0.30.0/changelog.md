# akbun-taskq 0.30.0

## Added

- bot 브라우저의 클릭과 입력에 승인 게이트를 넣었다. bot이 처음 보는 사이트에서 클릭하거나 입력하려 하면 실행하지 않고 Must check에 "Allow this site" 요청을 띄우며, 허용한 사이트는 계속 쓸 수 있다. 허용한 사이트에서도 구매, 결제, 전송, 게시, 삭제처럼 되돌릴 수 없어 보이는 클릭과 그런 칸의 제출은 그 동작 하나를 한 번 승인받아야 실행된다. 비밀번호 칸 입력은 항상 거부한다.
- 브라우저 창 위에 클릭·입력을 허용한 사이트가 칩으로 보이고, ×로 허용을 취소한다(`DELETE /api/bots/:name/browser/sites/:host`).
