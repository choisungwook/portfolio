# akbun-taskq 0.31.0

## Added

- task 상태보드에서 카드를 끌어 다른 열에 놓아 상태를 바꾼다. 초안→대기, 로그인 필요→대기, 확인 대기→완료, 실패→대기·초안(재시도), 실행 중 열로 놓으면 직접 실행, 실행 중·승인 대기·로그인 필요→취소처럼 원래 있던 동작만 받고, 나머지 열은 놓을 수 없다.
- 마지막 실행이 실패한 task는 상태보드의 카드 제목 앞에 오류 아이콘이, 열 제목 옆에 그런 카드 수가 보인다.
- 작업 상세의 이력 버튼이 상세 위에 새 창을 열어 실행마다 시작 시각, 걸린 시간, 실행한 agent, 결과, 요약을 보인다.
- 작업 상세의 수정 버튼으로 제목과 의도를 고친다. 실행 중과 승인 대기에서는 꺼지고, 중지(취소)되거나 실패한 task는 고칠 수 있다.
- 설정 > 업데이트에서 설치를 마치면 다시 시작 버튼이 나온다. taskq가 bot과 실행을 멈추고 새 버전으로 다시 뜨며, 열려 있던 페이지는 그대로 이어진다.

## Changed

- task 상태보드를 세 칸으로 나눴다. 왼쪽은 초안(inbox), 가운데는 진행 상태 두 줄, 오른쪽은 위에 실패와 취소, 아래에 완료다. 각 열은 창 높이 안에서 따로 스크롤된다.
- 작업 상세의 버튼(수정, 이력, 직접 실행, 상태 버튼)을 오른쪽 위로 옮겼다.
- owner bot이 없는 task는 직접 실행할 수 없다. 버튼이 꺼지고 API도 거절한다. 큐의 자동 실행 설정은 그대로다.

## Fixed

- bot 대화의 모델 메뉴가 "Opus", "Sonnet"처럼 계열 이름만 보여 어떤 버전인지 알 수 없던 문제. 이제 "Opus 5.5"처럼 버전을 붙인다.

- 작업을 바꾸는 요청(`PATCH /tasks/:id`)이 보내지 않은 필드까지 지우던 문제. workflow나 우선순위만 바꿔도 제목, 주의 사항, 저장소가 사라졌다. 이제 보낸 필드만 바뀌고, 빈 제목은 제목을 지운다.

## SDK

Claude Agent SDK의 `supportedModels()`가 주는 `resolvedModel`(없으면 `value`)에서 버전을 읽는다.
