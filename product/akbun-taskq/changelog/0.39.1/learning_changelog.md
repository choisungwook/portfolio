# akbun-taskq 0.39.1 학습 노트

짧은 기간에 기능이 여럿 바뀌면서 결정 문서와 테스트가 코드보다 뒤처졌다. 이번에는 둘을 지금 코드에 맞췄다.

## 엉뚱한 이유로 통과하던 테스트

가장 위험한 것은 실패하지 않는 테스트였다. 수동 인계 테스트는 "인계를 기다리는 작업은 직접 실행이 409"를 확인하려 했지만, 0.31.0에서 담당 bot이 없는 작업의 직접 실행이 먼저 409가 되면서 인계와 상관없이 통과했다. workflow 테스트도 이미 실행 중인 작업에 직접 실행을 걸어 "이미 실행 중" 409로 통과했다. 두 테스트 모두 상태 코드만 보던 것을 오류 문구까지 보게 바꿨다. 상태 코드 하나만 확인하는 거부 테스트는 거부 이유가 여러 개로 늘어나는 순간 의미를 잃는다.

## 결정 문서

결정은 바뀔 때마다 새 문서가 생기기 쉽다. 예산을 없앤 이야기가 거부된 turn 문서에 섞여 있었고, 사용량 제한 문서와 resident bot 문서에도 비슷한 목록이 있었다. 한 문서(no-usage-limits)로 모으고 나머지는 링크만 남겼다. 지난 세션에 고친 기능(저장소 여러 개, 세션과 task 분리, 데스크톱 진행 줄)이 다른 결정의 문장과 어긋나던 곳도 고쳤다.
