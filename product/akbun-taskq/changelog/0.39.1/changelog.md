# akbun-taskq 0.39.1

## Changed

- 사용자에게 보이는 동작은 바뀌지 않았다. 결정 문서와 테스트를 정리했다.
- 결정 문서: 코드와 어긋난 설명을 고치고(작업 worktree 체크박스, 세션을 이어 쓰는 경우, OpenAI bot 경로별 대화와 권한, 사이드바 메뉴, 데스크톱 앱 껍데기, workflow 실행 조건, 작업 담당 bot), 예산 이야기는 한 문서로 모으고, 같은 설명이 두 곳에 있던 것은 원본 문서 링크로 바꿨다.
- 테스트: 엉뚱한 이유로 통과하던 [critical] 테스트 두 개(수동 인계 대기, workflow 작업의 직접 실행 거부)가 의도한 이유를 확인하게 고치고, 낡은 이름과 메시지를 맞추고, 다른 테스트와 겹치거나 아무것도 검사하지 않던 테스트·줄을 지웠다(786개 → 778개).
