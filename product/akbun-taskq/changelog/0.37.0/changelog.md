# akbun-taskq 0.37.0

## Added

- 작업에 저장소(로컬 폴더, 보통 GitHub checkout)를 여러 개 지정한다. 작업 상세의 저장소 줄에서 추가하고 빼며, 첫 번째가 기본 작업 폴더다. bot은 작업을 시작할 때 저장소마다 어디서 작업할지 받는다.
- 저장소마다 그 작업의 worktree가 아래에 읽기 전용으로 보인다(경로, 브랜치).
- worktree 사용은 작업 상세의 체크박스로 켜고 끈다. 켜면 git 저장소마다 worktree를 만들고, 끄면 내 폴더에서 바로 작업한다.
- 정리 프로그램이 worktree 폴더를 지웠으면 "사라짐 · 다음 실행 때 다시 만듦"으로 보인다. 다음 실행(직접 실행이나 담당 bot의 작업 시작)이 그 작업의 브랜치로 worktree를 다시 만든다.

## SDK

code 작업 실행은 모든 저장소의 작업 폴더를 `additionalDirectories`와 sandbox 쓰기 허용에 넣고, 작업 게이트도 그 폴더들에 쓰기를 허용한다.
