# akbun-taskq 0.38.0

## Added

- 설정 > Database에서 데이터베이스를 백업하고 내려받는다. taskq가 실행 중이어도 일관된 사본을 만들고, taskq 데이터 폴더(bot이 닿지 못하는 곳)에 남긴 뒤 내 컴퓨터로 내려받는다. 최근 백업도 다시 내려받을 수 있다.
- 같은 화면에서 백업 파일로 복원한다. 파일이 taskq 데이터베이스인지(손상 여부, 테이블, 더 새 버전의 스키마가 아닌지) 검사한 뒤 taskq가 다시 시작하며 그 파일로 바뀐다. 바뀌기 전의 데이터베이스는 백업으로 남는다.
- `taskq db export [FILE]`, `taskq db import FILE`로 터미널에서도 같은 일을 한다. 터미널에서 복원하면 다음 `taskq run` 시작 때 바뀐다.
