# akbun-taskq 0.40.1 학습 노트

0.40.0의 입력 기록은 기록을 둘러보기 시작한 순간의 글만 `historyDraft`로 남겼다. 그래서 불러온 메시지를 고친 뒤 ↑를 누르면 고친 글이 다음 기록으로 덮였다.

입력창의 `input` 이벤트에서 `historyAt`을 -1로 되돌렸다. 사용자가 글을 고치면 둘러보기가 끝난 것으로 보고, 다음 ↑는 고친 글을 새 draft로 저장한 뒤 가장 최근 기록부터 다시 시작한다. 코드가 `value`를 바꾸면 `input` 이벤트가 나지 않으므로 ↑↓로 기록을 채울 때는 둘러보기가 끊기지 않는다.
