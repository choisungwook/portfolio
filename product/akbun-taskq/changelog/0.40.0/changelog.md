# akbun-taskq 0.40.0

## Changed

- 초안에 담당 bot을 정하거나 바꿔도 bot이 일을 시작하지 않는다. bot 대화에는 "Task … is now yours" 할당 알림만 남고, 실행은 직접 실행(Run now)을 누를 때 시작하고, 초안을 대기로 올리면 그때 담당 bot에게 알림이 가서 bot이 맡아 처리한다. bot이 다른 bot에게 초안을 만들어 줄 때도 같다.
- task 상태보드의 진행 영역을 실행 중과 대기 두 열로 줄였다. 대기열, 승인 대기, 로그인 필요, 확인 대기는 대기 열에 함께 있고 카드마다 어떤 대기인지 상태 표시가 붙는다.
- 상태보드 카드는 상태와 관계없이 같은 회색 테두리다.
- bot 대화의 작업 중 바가 화면 전체가 아니라 대화 열 너비에 맞는다.
- bot 대화 오른쪽의 컨텍스트 열은 파일·폴더·브라우저 창을 열어도 오른쪽 끝에 남고, 창은 대화와 그 열 사이에 열린다.

## Added

- 내가 보낸 메시지 아래에 복사 버튼이 있다.
- 입력창에서 ↑를 누르면 그 bot에게 보낸 메시지가 최근 것부터 차례로 채워지고, ↓를 누르면 되돌아가 쓰던 글로 돌아온다.
