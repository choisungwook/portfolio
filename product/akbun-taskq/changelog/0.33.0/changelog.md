# akbun-taskq 0.33.0

## Changed

- task 상태보드의 세 칸을 테두리와 제목(초안함, 진행, 결과)이 있는 패널로 나눴다. 가운데 진행 패널의 열 사이에 흐름을 보이는 화살표가 돌아왔다.
- bot 대화의 모델과 노력(effort) 메뉴를 Claude Desktop처럼 버튼 하나로 합쳤다. "Opus 5.5 · 중간"처럼 지금 값을 보이고, 열면 모델 목록과 노력 단계(낮음, 중간(추천), 높음, 엑스트라, 최대(사용량 많음))가 체크 표시와 함께 나온다. "기본 effort"는 없어졌다. 노력이 비어 있거나 그 모델에 없는 단계인 bot은 대화를 처음 열 때 추천 단계로 정해지고, 모델을 바꾸면 새 모델에 없는 단계도 추천 단계로 바뀐다. 노력만 바꾸는 저장은 skill·plugin을 다시 불러오지 않아 대화에 알림이 남지 않는다.
- bot 대화의 머리글에는 아바타와 이름만 보인다. 역할, 권한 모드, 설명은 이름에 마우스를 올리면 보인다.
- bot 대화와 사이드바의 시각에 마우스를 올리면 `26/11/21 (토) 17:28:50`처럼 정확한 시각이 보인다.
- 사이드바의 "검색"을 "통합 검색"으로 바꿨다. 작업뿐 아니라 위키, 파일, 대화까지 찾는다.
- 사이드바 맨 위 taskq 아바타 아래에 "대화 열기" 표시를 더하고, 마우스를 올리면 테두리와 배경이 생겨 버튼으로 읽히게 했다.
- 주간 점검을 설정에서 왼쪽 메뉴로 옮겼다. 모든 값은 데이터베이스에서 센 것이고 AI를 부르지 않는다는 안내를 함께 보인다.
- 위키, 워크플로우, 공용 폴더 화면을 bot 대화처럼 배치했다. 제목 줄 아래 구분선을 두고 블록 사이 간격을 고르게 했으며, 위키는 내보내기·가져오기가 제목 줄 오른쪽에 있고 목록과 본문 사이가 넓어졌다.
