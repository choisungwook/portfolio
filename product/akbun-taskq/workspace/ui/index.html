            Shared folder

            Every bot reads and writes this folder at the same path. Attached files are saved under attachments/.

            Plugins

            Skills and plugins registered here can be chosen per bot in its settings. Update pulls a git checkout and reloads every bot that uses it.

            OpenAI bots use the same skills (they read SKILL.md with the read_skill tool when they need one) and the MCP servers below. Claude Code plugins do not load in the OpenAI Agents SDK.

            Skills for bots

            Agent skill folders (with SKILL.md) that bots can load. Each bot picks its own in its settings.

              Plugins for bots

              Claude Code plugin folders (with .claude-plugin/plugin.json): skills, commands, hooks and MCP servers together.

                MCP servers for bots

                A command started over stdio for the bots that pick it, Claude and OpenAI alike. It runs as you, outside the bot gate: register only servers you trust, and keep keys in your environment, not here.

                  Official marketplace

                  The plugins in Anthropic's official marketplace, listed for reference. Nothing is installed: clone one and register its folder above to use it.

                      Bot settings

                      Role, instructions, model, permissions, skills and limits start with defaults; change them later with the gear next to the bot.

                      Charter

                      What this bot owns, what good looks like, and what it never does without asking you. It is added to the bot's standing orders.

                      Permissions and gate

                      taskq's own data and config are always off limits; a call that reaches them stops the turn and pauses the bots.

                      Skills, plugins and MCP servers

                      Registered in the Plugins menu. Saving copies the chosen skills and plugins for this bot; Reload copies them again. Plugins load only in Claude bots.

                      Routines

                      Work this bot does without being asked: on a schedule (cron in local time: "0 7 * * 1-5" is 7am on weekdays) or when a task fails, a task is created, or a webhook is called. Bots can also set routines when you ask them in chat.

                        Connections

                        How bots reach their models. Claude bots share the provider chosen below (it starts from taskq.config.json); an OpenAI bot uses the sign-in chosen in its settings, and on Bedrock the AWS profile chosen below; Kiro bots share the kiro-cli login. A bot that does not answer usually has a failing connection here.

                        How bots sign in

                        Pick the AWS profile from this machine (an SSO profile uses the short-term credentials of aws sso login). Saving applies from the next turn and overrides taskq.config.json.

                        Claude
                        OpenAI on Amazon Bedrock

                        Kiro (AWS) sign-in

                        Kiro bots use your AWS IAM Identity Center session. Enter your SSO start URL and region and sign in: kiro-cli shows a code to approve in the browser and keeps the session; taskq stores no token.

                        Rate limits

                        Limits for all bots together, and the defaults each bot uses unless its own settings say otherwise.

                        Usage

                        Tokens and cost of every bot session, by SDK. OpenAI cost is estimated from the prices in taskq.config.json; the ChatGPT plan has no per-turn price; Kiro reports credits when kiro-cli gives them.

                        Weekly review

                        Did each bot and routine run, did it go well, and would you miss it? A bot that checks its own work misses what it misses, so a few recent results are picked for you to check by hand.
