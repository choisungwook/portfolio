              Queue

              Off, a task without an owner runs only when you press its run button. A bot's task always waits for that bot.

              Skills for bots

              Agent skill folders (with SKILL.md) that bots can load. Each bot picks its own in its settings.

                Plugins for bots

                Claude Code plugin folders (with .claude-plugin/plugin.json): skills, commands, hooks and MCP servers together.

                  Notifications

                  Show system notifications for handoffs and critical alerts.

                  Access skills

                  An access skill is one of your Claude Code skills that signs in to the account a task works on. taskq stores only its path.
