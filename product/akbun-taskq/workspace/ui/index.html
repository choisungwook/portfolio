            Plugins

            Skills and plugins registered here can be chosen per bot in its settings. Update pulls a git checkout and reloads every bot that uses it.

            Agent skill folders (with SKILL.md) that bots can load. Each bot picks its own in its settings.

              Claude Code plugin folders (with .claude-plugin/plugin.json): skills, commands, hooks and MCP servers together.

                Official marketplace

                The plugins in Anthropic's official marketplace, listed for reference. Nothing is installed: clone one and register its folder above to use it.

                          Settings

                          Appearance

                          Rate limits

                          Limits for all bots together, and the defaults each bot uses unless its own settings say otherwise.

                          Folders

                            Queue

                            Off, a task without an owner runs only when you press its run button. A bot's task always waits for that bot.

                            Notifications

                            Show system notifications for handoffs and critical alerts.

                            Access skills

                            An access skill is one of your Claude Code skills that signs in to the account a task works on. taskq stores only its path.

                              Skills found on this machine

                                Database

                                The SQLite file that holds every task, run and event. Its location is fixed while taskq is running.

                                Configuration

                                Read from taskq.config.json. These values change only when that file is edited and taskq is restarted.
