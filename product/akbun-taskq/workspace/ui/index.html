                            Database

                            The SQLite file that holds every task, run and event. Its location is fixed while taskq is running.

                            Backup and restore

                            A backup is a full copy of the database made while taskq runs; it is kept in taskq's data folder and downloaded to your computer. Restoring replaces every task, run, bot and setting with the file's; the current database is kept as a backup first, and taskq restarts.

                              Configuration
