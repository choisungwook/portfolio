# Decisions

작업 중 내린 의사결정을 "결정 - 이유" 구조로 기록한다. 파일명은 `YYYY-MM-<주제>.md` 형식을 사용한다.

## 목록

* [The macOS desktop app is a Tauri window around the released executable](2026-11-desktop-app-shell.md) - The app starts the bundled taskq through the login shell and shows its page; it has no updater of its own.
* [OpenAI on Bedrock calls inference profiles, listed with a hand-written SigV4 request](2026-11-bedrock-inference-profiles.md) - The model list comes from ListInferenceProfiles and openai.* ids become the region's us./global. profile.
* [A conversation over a token limit is handed over to a new session by the bot itself](2026-11-session-handover.md) - Past 100,000 tokens the hub asks the bot for a handover note and resets the session; Codex compacts itself at the same limit.
* [A turn the provider refused is not retried](2026-11-rejected-turns.md) - A 4xx on the OpenAI Agents SDK path sets the messages aside at once instead of retrying.
* [Store tasks in SQLite, not in markdown, JSON or YAML files](2026-11-storage-sqlite.md) - One SQLite file in WAL mode holds every table; plain files were rejected because of locking.
* [Run TypeScript by type stripping and ship the UI as static modules](2026-11-no-build-typescript-static-ui.md) - No bundler and no UI framework; the first idea was React with Vite and a calendar library.
* [Three inference providers selected by config](2026-11-inference-providers.md) - bedrock, api_key and subscription differ only in the child environment taskq builds.
* [Approval waits on a database row, woken by events](2026-11-db-driven-approval.md) - A pending approval is a database row, not an in-memory promise.
* [Approval shows and stores the exact input, bound to a request id](2026-11-approval-shows-exact-input.md) - The unmasked input lives in its own table until decided; decisions name a request id and the API needs a per-start token.
* [Task permission profiles follow how the SDK evaluates a tool call](2026-11-permission-profiles.md) - Profiles per task type for runs the queue or the run button starts; bots use their own per-bot permission mode.
* [The runner waits on an in-process wake signal with a 60 second fallback](2026-11-wake-instead-of-poll.md) - pollSec went from 2 to 60 seconds; API writes, run ends and event writes wake waiters at once.
* [UI themes implement a token contract, and status and notification patterns follow IBM Carbon](2026-11-carbon-design-system.md) - Component CSS reads only contract tokens, so a theme is one file; Carbon's status and notification patterns stay under the current Astryx theme.
* [New features start from an interface](2026-11-interface-first.md) - The interface comes first and callers import only it; the first implementation is wired in one place.
* [Agent SDKs plug in behind one AgentBackend interface](2026-11-agent-backend-interface.md) - createWorker, preflight and ask; the gate policy stays shared and each backend maps its own hook to it.
* [A call that reaches taskq itself stops the run for review](2026-11-tamper-stops-run.md) - Sandbox-off, data directory, taskq config and ~/.claude writes end the session; other denials only refuse the call.
* [Release a bun-compiled binary that embeds Claude Code](2026-11-release-bun-binary.md) - One executable per platform built by bun; Node SEA and requiring an installed claude were rejected.
* [Resident bots are resumed sessions with an async mailbox, stopped by Pause](2026-11-resident-agent-team.md) - Each bot is one session resumed per turn; bots talk through an async mailbox and share a SQLite wiki; the retry limit and Pause stop them.
* [A task has one owner bot; several bots meet only in a bounded discussion](2026-11-task-ownership-and-discussions.md) - tasks.owner holds one bot per task and create_task refuses look-alike work; debates run as ordered, round-limited threads that a moderator closes.
* [Team wiki search is trigram FTS plus link expansion, behind a WikiSearch interface](2026-11-wiki-hybrid-search.md) - No embedding model; trigram FTS fixes Korean substring recall, [[links]] add one hop, and the wiki is mirrored to files so graphify can index it.
* [Navigation is a left sidebar where bots read like chats, and the user-facing name is Bots](2026-11-soft-theme-sidebar.md) - The sidebar holds the orchestrator, new task and search, every view and the bot chat list, with alerts and settings at its foot; no tab row or top bar.
* [Bots work on their own tasks with per-bot permissions; the run button stays a one-off run](2026-11-bots-execute-tasks.md) - Tasks are notes a bot takes and closes in its own session; each bot sets its permission mode (auto), sandbox (off) and blocked commands (none), while taskq's own data is always off limits.
* [Bots share one folder, keep memory and settings in SQLite, and cancel a turn without retrying it](2026-11-bot-workspace.md) - The shared folder is mounted into every bot session; uploads stay JSON; memory, language and theme live in SQLite; a cancelled turn's work is not replayed.
* [Workflows are step graphs a bot executes and taskq judges](2026-11-workflows-run-by-bots.md) - A workflow is an n8n-like graph of steps; a bot does the work and reports each step, taskq enforces order and evidence and decides success, and runs keep a snapshot so a deleted workflow stays in the history.
* [OpenAI bots plug in behind TeamBackend, with tools chosen by permission mode](2026-11-openai-bot-backend.md) - An OpenAI Agents SDK backend runs bots with the same hub, tools, turn limit and gate; on the API key path the Responses API keeps the conversation, and the permission mode picks file and shell tools.
* [The CLI and MCP server reach every route through one table of operations](2026-11-operations-for-cli-and-mcp.md) - Each API route is a named operation; taskq api and the MCP tools taskq_<operation> call the route in their own process against the same database, and a test fails when a route has no operation.
* [A code task in a git repository works in its own worktree, made when the task is created](2026-11-task-worktrees.md) - createFromInput makes a worktree and branch per code task; since 0.37.0 a task has several repositories, a worktree checkbox, and a deleted worktree is made again on the next run.
* [Wiki export and import run as resumable background jobs, and import digests files into pages](2026-11-wiki-transfer-jobs.md) - A small job runner with checkpoints runs export (zip at deflate level 9) and import; import turns documents into searchable, linked pages instead of storing an archive.
* [ChatGPT-plan and Kiro bots run their own CLIs per turn, with taskq's tools served over MCP](2026-11-bot-runtimes-beyond-sdks.md) - OpenAI bots pick API key, Bedrock or the ChatGPT plan (codex exec); Kiro bots run kiro-cli headless with the user's AWS SSO session; both get the bot's team tools from `taskq mcp --bot`.
* [The UI takes Meta's Astryx design tokens, not its React components](2026-11-astryx-design-system.md) - astryx.css is the theme the UI loads, light by default; the static UI stays framework-free and soft.css and carbon.css remain as unused implementations.
* [The UI follows impeccable's craft floor for product surfaces](2026-11-impeccable-ui-floor.md) - Checked against pbakaus/impeccable (Operate mode, craft floor, audit); one SVG icon set, no side stripes, AA contrast and themed browser surfaces became rules.
* [Session transcripts stay where each runtime puts them, and Settings lists them per runtime](2026-11-session-transcript-locations.md) - Claude keeps ~/.claude/projects because moving CLAUDE_CONFIG_DIR also moves the login and user settings; Settings > Folders and a bot's session folder show each runtime's store.
* [Bots have no spend or usage limit; Pause is how the user stops them](2026-11-no-usage-limits.md) - 0.20.0 removed the bots' budgets and 0.26.0 the hourly turn limits; concurrency and model turns per turn come from taskq.config.json, the handover size is fixed at 100,000 tokens.
* [Marketplace plugins install at the commit the marketplace lists, into TASKQ_HOME/plugins](2026-11-marketplace-plugin-install.md) - Only the pinned commit is fetched (sparse for a subfolder), registered under the marketplace name, updated by installing again, and deleted with its row.
* [Registered skills, plugins and MCP servers are shared by type; every runtime signs in from one Connections section](2026-11-shared-registry-and-signin.md) - Bots no longer pick from the registry, a Claude bot chooses its own sign-in, Connections tests one method in 5 seconds, and routines were removed.
* [A bot's tool calls are recorded in SQLite and folded into its conversation](2026-11-turn-steps-in-conversation.md) - team_turn_steps from each backend's pre-call point; the chat folds calls in a row into one line with a live spinner. Kiro records none.
* [A task is never tied to a session; a new run is told what the last one did](2026-11-task-not-tied-to-session.md) - Retry always starts a new session and there is no resume command; the last run's outcome, summary and tool calls go into the new prompt.
* [Every bot carries a built-in taskq skill written from the running version](2026-11-builtin-taskq-skill.md) - skills/taskq and manual.md ship in the binary, are written into TASKQ_HOME on every start, load outside the registry and are read only.
