    Project Resolution
    
      
      
      
      
      
    
        The broadcast rates are exact ratios — 29.97 is 30000/1001 — so a camera file
        stays in step with itself for the whole edit. Changing this moves every clip to
        the nearest frame of the new rate rather than leaving it on its old frame number.
      
    
      
    
        This is the editing canvas. Render presets set the long edge and keep this shape,
        so a vertical project renders vertical.
