# Edit point navigation

## Decision

- 클립의 시작·끝 프레임을 편집점으로 사용
- 위·아래 화살표와 Page Up·Page Down으로 이전·다음 편집점 이동
- 대상 트랙이 없으면 보이는 모든 트랙, 있으면 해당 트랙만 탐색
- Home·End로 타임라인 시작·끝 이동

## Reason

- 눈으로 재생헤드를 맞추지 않고 클립 경계에서 바로 자르기 가능
- Resolve와 Premiere 사용자가 익숙한 기본 키를 함께 지원
- 트랙이 늘어 편집점이 촘촘해져도 대상 트랙으로 탐색 범위 축소

## Tradeoffs

- 대상 트랙은 프로젝트 파일에 저장하지 않는 편집 세션 상태
- 숨긴 대상 트랙에는 이동할 편집점이 없으므로 키 입력이 현재 위치 유지
