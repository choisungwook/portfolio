# Playback proxies

## Decision

- 장변 1920px 초과, H.264가 아닌 코덱, 키프레임 간격 2초 초과 중 하나에 해당하면 프록시 생성
- 첫 30초의 video packet을 조사해 가장 긴 키프레임 간격 판정
- 최대 1920px 장변 H.264 프록시에 0.5초 간격 키프레임 강제
- 프로젝트의 `proxies/` 폴더에 미디어와 원본 경로·수정 시각·정책 버전 manifest 저장
- 재생 프로젝트 복사본에서만 프록시 경로 사용
- 자산 행에 해상도·코덱·키프레임 판정 근거 표시
- `Playback → Proxy Media…`에서 프록시 재생 전환, 남은 작업, 재생으로 보류된 상태 제공

## Reason

- preview quality는 합성 크기만 줄이고 원본 디코드 비용은 줄이지 못함
- 1080p HEVC·ProRes와 긴 GOP 카메라 원본도 seek 비용이 큼
- 0.5초 키프레임은 프록시 seek가 디코드해야 할 구간을 제한함
- 원본 경로, 수정 시각, 정책 버전 변경 시 기존 프록시 무효화
- export는 문서의 원본 경로를 계속 사용

## Tradeoffs

- 해상도를 낮추지 않는 1080p 원본도 코덱과 GOP 때문에 프록시 생성 가능
- 30초 packet probe 비용 추가
- 프록시 준비 전 원본 재생 유지
- 백그라운드 변환 비용과 프로젝트 폴더 용량 증가
- 재생 중 새 작업은 대기하고 실행 중 작업은 일시정지
