# Akbun

An Obsidian theme on the Catppuccin palette: Latte in light mode, Mocha in dark mode.

- The file explorer is plain: one muted color for every folder and file, no per-folder colors.
- The active file is loud: accent background, bold text, and a marker on the left edge.
- Heading, bold, italic, link, highlight, and active-file colors are single CSS variables. Change them from the Style Settings plugin, or edit the block at the top of theme.css.

## Install

Copy manifest.json and theme.css into `<vault>/.obsidian/themes/Akbun/`, then pick Akbun under Settings, Appearance, Themes.

## Tune colors

Install the Style Settings community plugin. The Akbun section lists every tunable color with its light and dark value. Without the plugin, edit the `--akbun-*` variables in theme.css.
