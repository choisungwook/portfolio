# python 작성 규칙

indent, 이름 형식, 타입 힌트, docstring은 [ruff.toml](../../ruff.toml)이 정하고 PR에서 `ruff check`와 `ruff format --check`가 검사한다. 아래는 ruff가 판정하지 못하는 것이다.

- 프로젝트 관리, 패키지 관리, 파이썬 가상환경은 uv
- 코드를 성능관점에서 잘 짜는것 보다 잘 읽히는 코드를 작성
- 함수는 최대한 짧게 작성, 20라인 이상이면 리팩토링 고려
- 함수는 하나의 일만 하도록 작성
- docstring에는 함수의 목적과 입력/출력을 설명
- 불필요한 주석은 피하고, 코드 자체가 명확하도록 작성
- 예외 처리는 명확하게, 필요한 경우 사용자 정의 예외 클래스 작성
