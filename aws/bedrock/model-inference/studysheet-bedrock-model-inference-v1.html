두 입구

Runtime과 Mantle은 API 표면이 다릅니다

bedrock-runtime

  • InvokeModel, Converse
  • 직접적인 model payload 제어
  • Nova Canvas 이미지 생성

bedrock-mantle

  • Responses, Chat Completions
  • OpenAI·Anthropic SDK 호환
  • stateful response와 별도 quota

새 앱은 Mantle 우선, 모델·기능이 Mantle에 없거나 native API가 필요하면 Runtime을 선택합니다.

Mantle의 정체

Mantle은 Bedrock의 새 이름이 아닙니다

Mantle은 `bedrock-mantle` endpoint 뒤의 분산 inference engine입니다. 기존 `bedrock-runtime`도 계속 지원됩니다.

판단선택
기존 OpenAI SDK 코드를 옮김Mantle + Responses API
모델 공통 AWS-native chat interfaceRuntime + Converse
이미지 생성 또는 native payloadRuntime + InvokeModel
Mantle에 아직 없는 모델Runtime

가장 흔한 혼동

Endpoint Region과 inference scope는 별개입니다

source endpoint
bedrock-runtime.us-east-1.amazonaws.com
+
global.* modelId
→
eligible destination Region

`bedrock-runtime.global` URL을 만드는 것이 아닙니다. 호출은 regional endpoint로 보내고, published inference profile ID가 처리 범위를 정합니다.

라우팅 범위

In-Region, Geographic, Global은 경계가 다릅니다

ScopemodelId 예처리 가능 범위
In-Region`anthropic...`source Region 하나
Geographic`us.anthropic...`US 같은 지정 geography 내부
Global`global.anthropic...`eligible commercial Regions

처리 범위가 넓을수록 throughput 선택지는 커집니다. 데이터 residency가 엄격하면 그만큼 범위를 좁힙니다.

모든 모델이 세 ID를 전부 제공하지는 않습니다. model card에 공개된 ID만 사용합니다.

비용

청구 기준은 호출을 승인한 AWS 계정입니다

  • Playground: 로그인한 AWS 계정의 Bedrock usage
  • boto3: credential chain이 가리키는 AWS 계정의 usage
  • OpenAI SDK + Bedrock API key: key를 발급한 AWS 계정의 usage
  • Runtime과 Mantle: 같은 모델의 per-token 가격은 동일
  • Global/Geo: 별도 routing fee 없이 source Region 기준 가격

텍스트는 주로 input/output token, 이미지는 생성 수와 설정으로 과금됩니다. 가격 숫자는 실행 직전 pricing page에서 확인합니다.

로컬 준비

코드는 uv 환경 하나에서 실행합니다

dependency 설치

cd aws/bedrock/model-inference
make up

AWS 인증 후 Mantle 환경 변수 설정

export OPENAI_BASE_URL="https://bedrock-mantle.us-east-1.api.aws/v1"
export OPENAI_API_KEY="<BEDROCK_API_KEY>"

성공 판정. `uv run python -c "import boto3, openai"`가 오류 없이 끝납니다.

Mantle 미사용 테스트

boto3로 catalog와 text response를 확인합니다

Runtime 계열 model discovery

uv run python -m scripts.list_runtime_models --region us-east-1

Converse text generation

uv run python -m scripts.complete_runtime \
  --region us-east-1 \
  --model-id amazon.nova-micro-v1:0 \
  "Explain Amazon Bedrock in one sentence."

성공 판정. model ID 목록과 한 문장 응답이 출력됩니다.

Global 비교

URL은 그대로 두고 modelId만 바꿉니다

Global inference profile 호출

uv run python -m scripts.complete_runtime \
  --region us-east-1 \
  --model-id global.anthropic.claude-sonnet-4-5-20250929-v1:0 \
  "Reply with the word global."

`--region us-east-1`은 source endpoint를 선택합니다. `global.*`은 Bedrock이 선택할 수 있는 destination 범위를 넓힙니다.

성공 판정. `global` 응답이 출력되고, source Region의 CloudTrail·CloudWatch 관찰 지점을 유지합니다.

이미지 API

Nova Canvas는 Runtime의 InvokeModel로 호출합니다

이미지 한 개 생성

uv run python -m scripts.generate_image_runtime \
  --region us-east-1 \
  --model-id amazon.nova-canvas-v1:0 \
  --output output.png \
  "A small yellow submarine, technical cutaway, white background."

성공 판정. 1024×1024 `output.png`가 생성됩니다.

이 성공은 “OpenAI-compatible API로 모든 Bedrock modality를 호출할 수 있다”는 뜻이 아닙니다. model/API compatibility가 우선입니다.

Mantle 테스트

같은 Python에서 OpenAI client의 목적지만 바꿉니다

Mantle model discovery와 Responses API

uv run python -m scripts.list_mantle_models

uv run python -m scripts.complete_mantle \
  --model-id openai.gpt-oss-20b \
  "Explain Amazon Bedrock Mantle in one sentence."

예제는 `store=False`를 보내 conversation state를 저장하지 않습니다.

성공 판정. Mantle model ID 목록과 한 문장 응답이 출력됩니다. 비용은 AWS 계정에 기록됩니다.

Teach-back

어떤 설명이 정확할까요?

`global.*` modelId를 Runtime에서 사용하면 무엇이 바뀝니까?

  • `bedrock-runtime.global` endpoint로 접속합니다.
  • regional source endpoint는 유지하고 처리 가능한 destination 범위가 넓어집니다.
  • 비용이 OpenAI 계정으로 이동합니다.

Endpoint Region과 inference routing scope는 서로 다른 선택입니다.

마지막으로 자신의 말로 설명해 보세요. “Mantle을 선택하는 조건, Runtime을 선택하는 조건, 비용이 귀속되는 곳”을 각각 한 문장으로 말할 수 있으면 완주입니다.
